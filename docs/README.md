## TikTok app review: "This URL is not verified"

TikTok requires you to **verify URL ownership** for your Web URL, Terms URL, and Privacy URL before submission. Use **URL prefix** verification and the signature file:

1. In [TikTok for Developers](https://developers.tiktok.com/), open your app and click **URL properties** (at the top of the app page).
2. Choose **Verify by URL prefix**.
3. Enter this exact URL prefix:  
   `https://chouaib-629.github.io/automatedPublicherYoutubeShorts/`  
   Then click **Verify**.
4. TikTok will show a **signature file** to download (e.g. `tiktok_verify_xxxxx.html`).
5. Put that file in **this `docs/` folder** (same folder as `index.html`, `terms.html`, `privacy.html`).
6. Commit and push so the file is available at:  
   `https://chouaib-629.github.io/automatedPublicherYoutubeShorts/<filename>`  
7. Back in the TikTok portal, complete the verification (e.g. click Verify again or Confirm). Once the prefix is verified, your Web, Terms, and Privacy URLs using this prefix will be accepted.

After that, use these in App details:

- **Web/Desktop URL:** `https://chouaib-629.github.io/automatedPublicherYoutubeShorts/`
- **Terms of Service URL:** `https://chouaib-629.github.io/automatedPublicherYoutubeShorts/terms.html`
- **Privacy Policy URL:** `https://chouaib-629.github.io/automatedPublicherYoutubeShorts/privacy.html`

Reference: [TikTok – Register Your App](https://developers.tiktok.com/doc/getting-started-create-an-app) → "Verify URL ownership".
